# 生产环境缺口清单

本文档记录当前项目从“可演示完整平台”进入生产环境前还需要补齐的工程项。

## 当前可以用于演示/实验的能力

- CLI、FastAPI、Web 前端都可以触发扫描。
- 上传源码或 zip 后可以异步生成 JSON/Markdown 报告。
- 7 个智能体已经进入检测流水线。
- 支持 CodeBERT、GraphCodeBERT、mock scorer、图特征 baseline、轻量 GNN baseline。
- 支持 Juliet C/C++、Devign、Big-Vul/MSR manifest 评测。

## 上生产前必须补齐

| 方向 | 当前状态 | 生产要求 |
| --- | --- | --- |
| 身份认证 | 已有可选 API Key | 增加正式用户登录、Token、角色权限、项目级隔离 |
| 任务队列 | FastAPI BackgroundTasks | 改为 Celery/RQ/Redis 或等价队列，支持重试、取消、并发控制 |
| 数据库 | SQLite，已增加常用索引和 schema 版本记录 | 改为 PostgreSQL/MySQL，并接入 Alembic 等正式迁移工具 |
| 文件隔离 | 已做路径和 zip 安全检查 | 增加用户独立工作区、文件类型白名单、杀毒/恶意压缩包检测 |
| 资源限制 | 已限制最大文件数、总字节数、单文件字节数 | 增加超时、CPU/内存限制、进程隔离和并发配额 |
| 模型服务 | 本地进程直接加载模型 | 独立模型服务或模型缓存池，避免每个任务重复加载 |
| 日志审计 | 只有基础任务状态 | 增加结构化日志、审计日志、错误追踪和指标监控 |
| 部署 | 本地脚本 + Dockerfile + docker-compose + 健康检查 | 生产环境继续补镜像仓库、CI/CD 和多环境配置 |
| 安全策略 | CORS 已默认限制本地前端，上传大小、zip 解压和可选 API Key 已有限制 | 生产环境继续增加速率限制、正式登录体系和更细的安全策略 |
| 结果治理 | 报告本地存储 | 增加报告生命周期、敏感代码脱敏、访问控制和清理策略 |

## 建议生产化执行顺序

1. 引入 PostgreSQL 和数据库迁移，替代 SQLite。
2. 增加正式认证、项目空间和上传/评测文件隔离。
3. 增加扫描进程超时、CPU/内存限制和并发配额。
4. 用 Redis 队列承接扫描任务，增加任务取消、重试、超时和并发限制。
5. 把模型推理拆成独立服务或长驻加载器，减少重复加载成本。
6. 增加日志、监控、报告清理和安全审计。

## 生产判定

当前状态：适合课程设计、毕业设计演示、实验评测和小范围本地部署。

生产状态：尚未达到公网或多用户生产环境要求，主要缺口是正式认证权限、进程级资源隔离、任务队列、数据库迁移和运行时安全控制。
